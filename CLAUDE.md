# all_scripts: правила работы над репозиторием

## Баг: сначала тест
Каждый найденный баг сначала воспроизводится тестом (он падает), потом чинится (тест проходит). В описании PR — строка «Тест: путь::имя». Если автотестом воспроизвести нельзя — одной фразой почему и как проверено вручную.

## Проверка перед коммитом
`python -m pytest -q tests` (при узкой правке — только затронутые файлы).
