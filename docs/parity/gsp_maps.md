# Карты ГСП: паритет со старым скриптом

Источник: `apps/map_dashboards/Секторные_диаграммы_расходов_и_добычи_воды_по_ГСП_на_карте.py` (функции `create_output_excel` и далее).
Правило: каждый лист и график старого Excel получает интерактивный аналог в приложении (и по-прежнему выгружается в Excel). ✅ — есть, ≈ — есть частично, ☐ — не сделано.

## Таблицы старого Excel
| Старый лист | Что в нём | Состояние |
|---|---|---|
| `Сводка_все_сезоны` | итоги по скважинам для всех сезонов подряд | ✅ «Таблица → Все сезоны» и лист «Сводка все сезоны»; тест сверяет с `process_main_data` |
| `Отбор_<сезон>`, `Закачка_<сезон>` | итоги скважин за сезон (газ, дни, время работы, давление, вода по замерам) | ✅ «Таблица → Сезон, все столбцы» (время работы, простой, давление ГСП и объекта, замеры воды) и листы «Отбор/Закачка по сезонам» |
| `Тренды_по_скважинам` | наклон расхода и воды | ✅ страница «Тренды» |
| `Вода_по_направлениям` | средний водный фактор и расход воды по направлениям | ✅ лист «Вода по направлениям» (та же формула, что в старом скрипте); интерактивно вода видна кольцами на карте и в «Долях» |
| `Данные_для_графика_давления` | давление ГСП и объекта вместе с расходами ГСП по датам | ✅ страница «Давление»: под графиком давления суточный расход ГСП с тем же временем; лист «Давление и расход ГСП». ≈ В старом листе «суточный расход» брался из часового столбца (ошибка), здесь настоящий суточный; тест сверяет остальное с `create_pressure_flow_sheet` |
| `Гант_работы_скважин` | диаграмма Ганта по дням: расход в ячейке, цвет — отбор, закачка, простой | ✅ страница «Работа скважин → Гант по дням», лист в Excel (≈ цвет по расходу, простой серым; на экране один сезон) |
| `Сводка_долей`, `Доли_отбор_по_сезонам`, `Доли_закачка_по_сезонам`, `Направления_по_сезонам` | доли скважин и направлений по сезонам | ✅ страница «Доли», вкладка «Направления» + листы Excel; тест паритета со старой функцией |
| `Доли_ОТБОР_график`, `Доли_ЗАКАЧКА_график` | график доли выбранной скважины по сезонам (выпадающий список) | ✅ линия доли выбранной скважины (клик по строке таблицы) |
| `Карта_работы_по_сезонам` | матрица «скважина × сезон»: работала, не работала, нет данных | ✅ «Работа скважин → По сезонам», лист «Работа по сезонам» |
| `Очерёдность_ввода` | порядок ввода скважин по сезонам, подсветка «часы есть, расхода нет» | ✅ «Очерёдность ввода», лист «Очерёдность ввода» |
| `Карта_работы_по_месяцам` | матрица «скважина × месяц» с отметками выноса воды | ✅ «По месяцам» (дни или расход, точка — вода), листы «Работа по месяцам», «Расход по месяцам» |

## Карты на листах
| Старый лист | Что на нём | Состояние |
|---|---|---|
| `Обводнённость_<сезон>` + ввод (`create_combined_season_maps`) | слева карта обводнённости, справа — ввод по дате | ✅ вода на основной карте (кольца, ВФ) и раскраска «Обводнённость (окно)»; «Ввод по дате» — отдельная раскраска |
| `Обводнённость_ВСЕ` | одна карта обводнённости за все сезоны с глубинами | ✅ раскраска «Обводнённость (все сезоны)»; глубины — отдельной раскраской и в подсказке |
| `Ввод_ЗАК_<сезон>`, средние карты ввода | цвет по дате ввода и по рангу очерёдности | ✅ раскраска «Ввод по дате» для выбранного вида и сезона (в подсказке — номер по очерёдности и отставание от первой); ≈ карты «среднего» ввода по всем сезонам нет |
| `Глубина_перфораций` | карта глубин перфорации | ✅ раскраска «Глубина перфорации» (те же пределы 100–5000 м и шкала жёлтый → синий) |

## Интерактивность карты (сверх старого скрипта)
- Выбор нескольких скважин: Ctrl+клик и Shift+рамка; в панели сведений суммарный расход по дням, накопленные линии и список группы.
- Накопленный расход по дням для выбранной скважины.
- Настройки кругов: множитель размера, подпись (номер / расход / нет), «Только работающие».
