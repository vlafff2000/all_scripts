# Карты ГСП: паритет со старым скриптом

Источник: `apps/map_dashboards/Секторные_диаграммы_расходов_и_добычи_воды_по_ГСП_на_карте.py` (функции `create_output_excel` и далее).
Правило: каждый лист и график старого Excel получает интерактивный аналог в приложении (и по-прежнему выгружается в Excel). ✅ — есть, ≈ — есть частично, ☐ — не сделано.

## Таблицы старого Excel
| Старый лист | Что в нём | Состояние |
|---|---|---|
| `Сводка_все_сезоны` | итоги по скважинам для всех сезонов подряд | ≈ в Excel есть, интерактивной таблицы «все сезоны» нет |
| `Отбор_<сезон>`, `Закачка_<сезон>` | итоги скважин за сезон (газ, дни, время работы, давление, вода по замерам) | ≈ страница «Таблица» за окно сезона; столбцов времени работы и давления нет |
| `Тренды_по_скважинам` | наклон расхода и воды | ✅ страница «Тренды» |
| `Вода_по_направлениям` | средний водный фактор и расход воды по направлениям | ☐ |
| `Данные_для_графика_давления` | давление ГСП и объекта вместе с расходами ГСП по датам | ≈ давление есть, расход ГСП на одном графике с давлением — нет |
| `Гант_работы_скважин` | диаграмма Ганта по дням: расход в ячейке, цвет — отбор, закачка, простой | ☐ |
| `Сводка_долей`, `Доли_отбор_по_сезонам`, `Доли_закачка_по_сезонам`, `Направления_по_сезонам` | доли скважин и направлений по сезонам | ☐ |
| `Доли_ОТБОР_график`, `Доли_ЗАКАЧКА_график` | график доли выбранной скважины по сезонам (выпадающий список) | ☐ |
| `Карта_работы_по_сезонам` | матрица «скважина × сезон»: работала, не работала, нет данных | ☐ |
| `Очерёдность_ввода` | порядок ввода скважин по сезонам, подсветка «часы есть, расхода нет» | ☐ |
| `Карта_работы_по_месяцам` | матрица «скважина × месяц» с отметками выноса воды | ☐ |

## Карты на листах
| Старый лист | Что на нём | Состояние |
|---|---|---|
| `Обводнённость_<сезон>` + ввод (`create_combined_season_maps`) | слева карта обводнённости, справа — ввод по дате | ≈ вода есть на основной карте (кольца, водный фактор); раскраски «ввод по дате» нет |
| `Обводнённость_ВСЕ` | одна карта обводнённости за все сезоны с глубинами | ☐ |
| `Ввод_ЗАК_<сезон>`, средние карты ввода | цвет по дате ввода и по рангу очерёдности | ☐ |
| `Глубина_перфораций` | карта глубин перфорации | ☐ (глубины есть в сведениях скважины) |

## Файлы
| Старый выход | Состояние |
|---|---|
| `Карта_отбор_<сезон>_<ГСП>.png`, `Карта_закачка_…png` | ≈ PNG текущего вида; пакетной выгрузки по всем сезонам нет |
| интерактивная html-карта с бегунком | ✅ заменена приложением |
| GIF-анимация | ☐ (в приложении анимация по дням есть) |

## План (по одному PR)
1. Работа скважин: Гант по дням, «скважина × месяц» с водой, «скважина × сезон», очерёдность ввода.
2. Доли: доли скважин и направлений по сезонам, график доли выбранной скважины.
3. Раскраски карты: ввод по дате, глубина перфорации, обводнённость; вода по направлениям; давление вместе с расходом ГСП; таблица «все сезоны» и недостающие столбцы.
