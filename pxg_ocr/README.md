# Распознавание (OCR)

Русский веб-интерфейс к локальному MinerU: загрузка сканов (PDF, изображения, Word, Excel, PowerPoint), выбор качества и режима вычислений, ход работы, просмотр страницы исходника рядом с markdown / JSON, скачивание. Выбор файлов и сохранение — общий проводник (`pxg_core/fs_browse.py`).

Запуск: `Raspoznavanie.bat` / `bash raspoznavanie.sh`, из исходников `python -m pxg_ocr` (`--browser`, `--server [порт]`, по умолчанию 8770).

## Движок
Папка `ocr` рядом с программой (или `PXG_OCR_HOME`, на Windows запасной вариант `C:\OCR`): `python` (или `mineru-env`) с MinerU 4.1.7 и `mineru-home` с моделями tier standard. Устанавливать ничего не нужно, интернет не нужен. Запуск: `mineru-kit parse файл -o результат.zip -f zip --tier standard --ocr-mode ocr`; в zip лежат markdown, JSON и картинки.

Русский текст читает только tier **standard**; basic и flash кириллицу теряют.

## Режимы и память
- «Авто»: видеокарта NVIDIA, если свободно ≥ 7 ГБ (лимит `MINERU_VIRTUAL_VRAM_SIZE` = свободно − 2 ГБ, не больше 6); иначе процессор.
- «Только процессор» (`MINERU_DEVICE_MODE=cpu` и др.): видеопамять не нужна, ошибок памяти нет, ~4× медленнее. Для слабых карт (1050 Ti, 1650).
- Потоков процессора — половина ядер.
- Файлы обрабатываются по одному: распознавание занимает весь ПК.
- Результаты: `<проект>/OCR/<дата>_<имя>/` (markdown, JSON, картинки, meta.json); история — список этих папок. Удаление результата только по подтверждению.

Тесты: `python -m pytest -q tests/test_pxg_ocr.py` (движок подменяется заглушкой). Проверка на реальных сканах и на ПК с видеокартой — вручную.
