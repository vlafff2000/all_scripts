# all_scripts

Старые рабочие скрипты по ПХГ, разложенные по будущим приложениям. Все приложения строятся на стеке Газового атласа (Python-ядро, веб-интерфейс на React, переносной архив без установки Python).

| Папка | Что это | Состояние |
|---|---|---|
| `pxg_base/`, `pxg_core/` | «База ПХГ»: сбор и очистка данных, 17 модулей с веб-формами; общие функции чтения Excel | работает, `pxg_base/README.md` |
| `apps/schedule_tr/` | «Схедул ТР»: файлы для tNavigator | скрипты перенесены без изменений |
| `apps/gis_gvk/` | «ГИС и ГВК» | скрипты перенесены без изменений |
| `apps/reports/` | «Отчёты и файлы»: Word, html, архивы | скрипты перенесены без изменений |
| `atlas_candidates/` | графики и анализ, которые переедут в разделы Газового атласа | скрипты перенесены без изменений |
| `tools/`, `tests/` | сборка переносного архива, тесты | |

Меню «Базы ПХГ» показывает и скрипты из `apps/`: у них пока нет веб-формы, в карточке написана команда запуска.
