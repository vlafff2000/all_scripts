# all_scripts

Рабочие скрипты по ПХГ, разложенные по приложениям. Приложения построены на стеке Газового атласа: ядро на Python (Starlette), интерфейс на React + TypeScript (собранный `web/dist` в git не хранится: его собирает CI архивов), светлая и тёмная тема, переносной архив без установки Python.

## Что здесь

| Папка | Что это | Состояние |
|---|---|---|
| `pxg_base/` | «Работа с исходными данными»: сбор и очистка данных (расходы, уровни и давления, межколонные давления, include для tNavigator). 23 модуля, у каждого веб-форма | работает, `pxg_base/README.md` |
| `pxg_core/` | общий код приложений: чтение Excel с расходами (поиск заголовка, номера скважин, русские месяцы, сезоны) | работает |
| `gsp_maps/` | «Карты»: живая карта скважин с секторными диаграммами расхода газа и выноса воды, бегунок времени, сравнение сезонов, поскважинный анализ, работа скважин, доли, давление, тренды, выгрузка в Excel | работает, `gsp_maps/README.md`, чек-лист переноса `docs/parity/gsp_maps.md` |
| `pxg_finder/` | «Поисковик»: автономный файловый менеджер на ядре общего проводника: вкладки, две панели, поиск по имени (маски, регулярки, фильтры, индекс), предпросмотр, палитра команд Ctrl+K, избранное, цветные метки, копирование и перенос, корзина с восстановлением, поиск дубликатов; быстрая работа с сетевыми дисками | работает, `pxg_finder/README.md` |
| `schedule_pxg/` | «ГДМ»: schedule для tNavigator (история, прогноз, сценарии, графики, проверки); заменил «Схедул ТР» (теперь «ГДМ») и скрипты `apps/schedule_tr` | работает |
| `apps/gis_gvk/` | «ГИС и ГВК»: обработка ГИС, поиск ГВК | три скрипта без изменений; Эльпро перенесён в «Работу с исходными данными» (Создание и обновление БД: «Импорт данных ЭЛПРО»), веб-формы нет |
| «Отчёты и файлы» (группа в «Работе с исходными данными») | копирование файлов по маске из подпапок, распаковка архивов, копирование замеров давлений по шаблонам; у каждого веб-форма, `pxg_base/webspec.py` | работает |
| `apps/map_dashboards/` | старые скрипты карт (html-карта, секторные диаграммы) | остаются для сверки, тесты «Карт ГСП» берут из них эталонные функции |
| `tools/` | `build_portable.py`: сборка переносного архива; `make_icons.py`: рисует значки ярлыков (`tools/icons`) | |
| `tests/`, `.github/workflows/` | тесты и CI | |

Меню «Работы с исходными данными» показывает и скрипты из `apps/`: у них пока нет веб-формы, в карточке написана команда запуска.

## Запуск из исходников

```
pip install -r requirements.txt            # Python 3.13, последние версии библиотек
python -m pxg_base                         # консольное меню модулей
python -m pxg_base --server                # «Работа с исходными данными» в браузере, http://127.0.0.1:8766
python -m gsp_maps                         # «Карты», окно приложения
python -m gsp_maps --browser               # то же в браузере
python -m gsp_maps --server                # только сервер, порт 8767
python -m pxg_finder                       # «Поисковик», окно приложения (--browser, --server: порт 8769)
```

Интерфейс (разработка): `cd pxg_base/web`, `cd gsp_maps/web` или `cd pxg_finder/web`, затем `npm install && npm run dev` (/api проксируется на сервер) и `npm run build` (`web/dist` в git не коммитится).
Тесты: `python -m pytest -q tests`. Они работают на сгенерированных исходных файлах (отдельные генераторы тестовых данных в репозиторий не добавляются, настоящие файлы лежат у пользователя).

## Переносной архив

Для компьютеров без Python и интернета собирается один архив со всеми приложениями ПХГ (Атлас, «Работа с исходными данными», «Карты», «ГДМ», «ГИС и ГВК», отчёты) — в репозитории `gas_atlas`, см. его `tools/build_unified.py` и `.github/workflows/portable.yml` (Actions → «Единый архив ПХГ»). Отдельные архивы этого репозитория не собираются.

Ярлыки со значками на рабочем столе: `Sozdat_yarlyki.bat` (Windows) или `bash sozdat_yarlyki.sh` (РЕД ОС) в распакованном архиве.
