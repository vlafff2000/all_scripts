# all_scripts

Рабочие скрипты по ПХГ, разложенные по приложениям. Приложения построены на стеке Газового атласа: ядро на Python (Starlette), интерфейс на React + TypeScript (собранный `web/dist` лежит в git), светлая и тёмная тема, переносной архив без установки Python.

## Что здесь

| Папка | Что это | Состояние |
|---|---|---|
| `pxg_base/` | «База ПХГ»: сбор и очистка данных (расходы, уровни и давления, межколонные давления, include для tNavigator). 22 модуля, у каждого веб-форма | работает, `pxg_base/README.md` |
| `pxg_core/` | общий код приложений: чтение Excel с расходами (поиск заголовка, номера скважин, русские месяцы, сезоны) | работает |
| `gsp_maps/` | «Карты ГСП»: живая карта скважин с секторными диаграммами расхода газа и выноса воды, бегунок времени, сравнение сезонов, поскважинный анализ, работа скважин, доли, давление, тренды, выгрузка в Excel | работает, `gsp_maps/README.md`, чек-лист переноса `docs/parity/gsp_maps.md` |
| `apps/schedule_tr/` | «Схедул ТР»: schedule для tNavigator | основной скрипт теперь модуль «Базы ПХГ» с веб-формой; два остальных пока без формы |
| `apps/gis_gvk/` | «ГИС и ГВК»: обработка ГИС, поиск ГВК | восемь скриптов без изменений, веб-формы нет |
| `apps/reports/` | «Отчёты и файлы»: распаковка архивов, ссылки и копирование файлов Word, копирование замеров давлений | четыре скрипта без изменений, веб-формы нет |
| `apps/map_dashboards/` | старые скрипты карт (html-карта, секторные диаграммы) | остаются для сверки, тесты «Карт ГСП» берут из них эталонные функции |
| `tools/` | `build_portable.py`: сборка переносного архива | |
| `tests/`, `.github/workflows/` | тесты и CI | |

Меню «Базы ПХГ» показывает и скрипты из `apps/`: у них пока нет веб-формы, в карточке написана команда запуска.

## Запуск из исходников

```
pip install -r requirements.txt            # Python 3.9+, последние версии библиотек
python -m pxg_base                         # консольное меню модулей
python -m pxg_base --server                # «База ПХГ» в браузере, http://127.0.0.1:8766
python -m gsp_maps                         # «Карты ГСП», окно приложения
python -m gsp_maps --browser               # то же в браузере
python -m gsp_maps --server                # только сервер, порт 8767
```

Интерфейс (разработка): `cd pxg_base/web` или `cd gsp_maps/web`, затем `npm install && npm run dev` (/api проксируется на сервер) и `npm run build` перед коммитом, чтобы обновить `web/dist`.
Тесты: `python -m pytest -q tests`. Они работают на сгенерированных исходных файлах (отдельные генераторы тестовых данных в репозиторий не добавляются, настоящие файлы лежат у пользователя).

## Переносные архивы

Для компьютеров без Python и интернета. Архив содержит собственный Python (с tkinter), последние версии библиотек, которые для него существуют, и оба приложения.

| Система | Архив | Python | Запуск |
|---|---|---|---|
| Windows 10 и новее, x64 | `PXG_Base_portable_windows_x64.zip` | 3.14 | `PXG_Base.bat`, `Karty_GSP.bat`, `Skedul_PXG.bat`, `PXG_Base_console.bat` |
| Linux x86_64, glibc 2.17+ (целевая система РЕД ОС 7.3) | `PXG_Base_portable_linux_x64.tar.gz` | 3.13 | `pxg_base.sh`, `karty_gsp.sh`, `skedul_pxg.sh`, `pxg_base_console.sh` |

Для РЕД ОС 7.3 берутся только колёса manylinux2014, поэтому numpy и pandas там на последних версиях, у которых такие колёса ещё есть (numpy 2.2, pandas 2.3). Результаты «Базы ПХГ» пишутся в папку `pxg_runs` рядом с архивом.

Сборка вручную (нужны интернет и Python 3.9+): `python tools/build_portable.py windows` или `linux`, результат в `dist/`.
В GitHub: Actions → «Portable archives» → Run workflow (или тег `v*`). Задание собирает оба архива, запускает «Базу ПХГ», «Карты ГСП» и «Скедул ПХГ» из распакованного архива и выкладывает архивы как артефакты. Обычный CI (`CI`) гоняет тесты на Python 3.11 и 3.14 при каждом PR.
