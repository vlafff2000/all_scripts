# ГИС и ГВК

Обработка данных ГИС, создание LAS-файлов по базе ГИС, ГИС для авторского надзора. Эльпро перенесён в «Работу с исходными данными» («Импорт данных ЭЛПРО»).

Оставлены нужные скрипты; остальные удалены как не используемые. Скрипты без изменений (консольные или с окнами tkinter). Дальше по одному превращаются в модули с параметрами, как в «Работе с исходными данными».

«ГИС для авторского надзора» — извлекает из PDF-отчётов по скважинам (папка на скважину, сезон задаётся вручную) интервалы пачек, общую толщину Нг и глубину ГВК с абсолютной отметкой, и сводит всё в одну таблицу Excel.
