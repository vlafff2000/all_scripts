# Схедул ТР

Подготовка входных файлов для tNavigator: schedule, include-файлы давлений и расходов.

Скрипты перенесены сюда из корня репозитория без изменений (консольные или с окнами tkinter). Дальше по одному превращаются в модули с параметрами, как в «Базе ПХГ» (`pxg_base/webspec.py`).
