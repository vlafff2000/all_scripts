# Схедул ТР

Подготовка входных файлов для tNavigator: schedule, include-файлы давлений и расходов.

Скрипты перенесены сюда из корня репозитория без изменений (консольные или с окнами tkinter). Дальше по одному превращаются в модули с параметрами, как в «Базе ПХГ» (`pxg_base/webspec.py`).

Основной скрипт «Создание schedule файла технологического режима» уже переехал в «Базу ПХГ»: `pxg_base/modules/Создание_schedule_файла_технологического_режима.py`, веб-форма «Схедул ТР». Режимы закачка, отбор и прогноз (базовый) работают из формы; «Прогноз с варьированием» (окно редактора стратегий) пока только из консоли: `python -m pxg_base Создание_schedule_файла_технологического_режима`.

Остались как есть:

| Скрипт | Строк |
|---|---|
| Schedule_по_пропорциональным_коэффициентам_шаг_1_сутки.py | 1432 |
| Schedule_по_датам_замеров_давлений.py | 898 |

Это актуальные версии: более ранние варианты (для ЦКР, «одним скриптом», таблицы расходов газа) удалены, история в git сохранена.

Уже перенесены в «Базу ПХГ» (`pxg_base/modules/`, с веб-формой): include давлений (наблюдательные 1002, с пересчётом по MD, эксплуатационные), «факт из модели», перераспределение отборов , извлечение ключевых слов.
